# Data sources

The MVP trains on three tiers, described in `spec.md` §3:

1. **Public battery-degradation data** (NASA PCoE, CALCE, Kaggle RUL) for the
   Battery Health Index (BHI) model.
2. **Public credit-risk proxy data** (Kaggle "Give Me Some Credit", Zindi,
   FSD Kenya/CBK FinAccess) for the Repayment Risk Index (RRI) model.
3. **Locally generated synthetic Kenya-context data** (`ml/data/synthetic/`)
   that mimics real partner exports.

No new external dataset was required for the swap-cadence and fraud/anomaly
features added in this phase:

- The swap-cadence feature (`telemetry_cadence_proxy`) uses the existing
  `ml/data/synthetic/telemetry_readings.csv` generated by
  `scripts/generate_synthetic.py`.
- Anomaly-detection thresholds (physical bounds for state-of-charge and
  temperature, plus the state-of-charge jump limit) are sanity bounds
  calibrated against the same synthetic telemetry ranges (Kenyan climate
  norms ~18–31°C) rather than a new external corpus.
